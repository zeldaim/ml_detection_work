[웹 서버 VM 설치 - 192.168.20.10 (DMZ)]

전제
  - 이 VM 의 IP 가 192.168.20.10 (확인: hostname -I)
  - Docker, docker compose 설치됨
  - 빌드 시 인터넷 필요 (php:7.4-apache 이미지 + apt 패키지 다운로드)
  - DB VM(192.168.10.20) 을 먼저 띄워 둘 것
  - 방화벽: 192.168.20.10 -> 192.168.10.20:3306 허용

설치
  tar xzf shop-web.tar.gz
  cd sesac_shop_web_php
  sudo docker compose -f compose.web.yml up -d --build

확인
  curl -s http://192.168.20.10/api/v2/products | head -c 200    # 상품 JSON 이 나오면 DB 연결 OK
  브라우저: http://192.168.20.10/   (로그인: user1@example.com / Test1234!)

설정 (.env)
  DB_HOST=192.168.10.20      웹이 접속할 DB 서버 IP
  WEB_BIND=0.0.0.0           80 포트를 이 VM 의 모든 IP 로 연다
  V1_ALLOWED_NET=...         v1 레거시 API 를 호출할 수 있는 PC 대역 (밖이면 403)

로그: logs/app.log, logs/apache/shop_access.log, logs/apache/shop_error.log
중지: sudo docker compose -f compose.web.yml down
