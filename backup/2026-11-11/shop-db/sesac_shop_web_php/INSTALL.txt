[DB 서버 VM 설치 - 192.168.10.20 (LAN)]

전제
  - 이 VM 의 IP 가 192.168.10.20 (확인: hostname -I)
  - Docker, docker compose 설치됨
  - 인터넷 필요 (mysql:8.0 이미지 다운로드)

설치
  tar xzf shop-db.tar.gz
  cd sesac_shop_web_php
  sudo docker volume create sesac_shop_web_php_db-data    # 최초 1회 (DB 데이터 저장소)
  sudo docker compose -f compose.db.yml up -d

  -> 볼륨이 비어 있으므로 처음 뜰 때 deploy/shopdb-dump.sql (시드 데이터) 과
     deploy/mysql-init/02-user.sql (앱 계정 shopapp/1234) 이 자동으로 들어간다.
     덤프가 커서 첫 기동은 1~2분 걸릴 수 있다.

확인
  sudo docker compose -f compose.db.yml ps                 # STATUS 가 healthy 면 OK
  sudo docker compose -f compose.db.yml exec db mysql -ushopapp -p1234 shopdb -e "SELECT COUNT(*) FROM users;"

설정 (.env)
  DB_BIND=192.168.10.20      3306 포트를 열 이 VM 자신의 IP
  MYSQL_ROOT_PASSWORD        root 비밀번호 (볼륨을 처음 만들 때만 적용)

로그: logs/mysql/slow.log (모든 쿼리 기록, 읽을 때 sudo)
중지: sudo docker compose -f compose.db.yml down      (-v 붙이면 데이터 삭제되니 주의)
