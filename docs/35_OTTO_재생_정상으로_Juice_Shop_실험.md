## 2. 고친 것: LOF 와 중복 행

재생 데이터는 **완전히 같은 피처 행이 44번** 나온다(방문 = 페이지 로드 + 상품 1개 = 7요청. 로그가 초 단위라 간격 패턴까지 같아짐).
LOF 는 같은 점이 이웃 수(20)보다 많으면 밀도가 무한대가 되어 판정이 깨진다 → 첫 실행에서 B 의 LOF 탐지가 **0/32**(고장).
→ `supervised.py` 의 LOF 학습을 **고유 행만** 쓰도록 변경. 생성기 데이터(최대 중복 5)에도 적용되어 **A 의 LOF 수치가 docs/33 과 조금 다르다**
(docs/33 §5-1: 탐지 141/160 · 오탐 12% → 이번 A: 145/160 · 10.1%).

## 3. 결과

### 3-1. 지름길 없음 — 재생 정상은 생성기 정상과 피처 하나로 갈리지 않는다

정상끼리(재생 205 vs 생성기 214) 단일 피처 AUC 최대 `interval_cv` 0.833, 나머지 0.51~0.75. 0.99 이상 없음.

### 3-2. C — 생성기로만 학습하면 사람 같은 정상을 많이 오탐한다

| 모델 | 재생 정상 오탐 구간 | 한 번이라도 걸린 재생 출발지 |
|---|---|---|
| IF | 29/205 (14%) | 17/40 |
| LOF | 54/205 (26%) | 21/40 |
| AE | 50/205 (24%) | **35/40** |

학습 정상(생성기)의 5% 를 이상으로 두는 설정인데, OTTO 행동을 재생한 정상에선 14~26%. 생성기 정상이 '사람 같은 행동'을 덮지 못한다는 직접 근거.

### 3-3. A vs B — 재생 정상을 학습에 넣으면 (seed 0~4 합)

| 모델 | A 탐지 | B 탐지 | A 오탐 | B 오탐 |
|---|---|---|---|---|
| IF | 69/160 (43%) | **114/160 (71%)** | 5.2% | 5.7% |
| LOF | 145/160 (91%) | 139/160 (87%) | 10.1% | 9.0% |
| AE | 139/160 (87%) | **151/160 (94%)** | 9.0% | **5.7%** |
| IF\|LOF\|AE | 147/160 (92%) | 152/160 (95%) | 15.0% | **11.7%** |
| RF | 100/160 (62%) | 63/160 (39%) | 5.4% | 3.0% |

- **AE: 탐지 87→94%, 오탐 9.0→5.7%** — 둘 다 좋아짐. IF 는 탐지 43→71%(오탐 비슷). LOF 는 큰 차이 없음.
- 시드별 편차는 여전히 크다(예: B 의 AE 오탐 0%~14%, seed 2 가 가장 나쁨) — 평균만 보고 결론 내지 말 것.
- RF 는 탐지가 떨어짐(62→39%): 재생 정상이 '정상' 라벨로 들어가며 결정 경계가 바뀜. 처음 보는 종류 평가에서 RF 는 원래 불안정(docs/33 §5-2).

## 4. 이 결과로 말할 수 있는 것 / 없는 것

- 말할 수 있음: 생성기 정상만으로는 사람 행동 모양의 정상을 14~26% 오탐한다(C). 재생 정상을 학습에 더하면 AE·IF 는 탐지를 유지하거나 올리면서 생성기 출발지 오탐도 내려간다(B, AE 9.0→5.7%).
- 말할 수 없음: **실제 사람에게도 오탐이 줄어든다.** 평가 정상(10.16.1.1xx)은 여전히 생성기 출신이고, 재생도 실제 사람이 아니라 'OTTO 시간 패턴 + 우리 매핑 규칙'이다. 검색·오류·리뷰는 재생에 없다.
- 재생 40명 · 한 번의 샘플 시드(0) 결과. 재생 시드·인원을 바꿔 재현해야 한다.
